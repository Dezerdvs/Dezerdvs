## 👋 About me

I'm an Information Technology student (Information Systems & Technologies, IoT Software Technologies program) who likes building things that touch real hardware — sensors, embedded devices, and the backends that make sense of their data. My flagship project, **DoughIoT**, is a full IoT stack (ESP32 → Flask → real-time dashboard) that predicts bread dough readiness from live sensor data — built as my Bachelor's thesis.

- 🔭 Currently building **DoughIoT** — an IoT fermentation monitor with real-time sensor streaming
- 🌱 Comfortable across the stack: embedded C++ firmware, Python backends, C#/.NET services, and classic CS fundamentals
- ⚡ Fun fact: I've implemented AVL trees, Red-Black trees, and Dijkstra's algorithm from scratch — no shortcuts
